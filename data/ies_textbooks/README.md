# IES Civil textbooks (local)

Place **your own** Civil Engineering textbook extracts here as `.txt` or `.md` files
(e.g. exported chapters from SOM, Fluid Mechanics, Soil Mechanics, Environmental Engg.).

Then rebuild the RAG index:

```bash
npm run ies:textbooks
```

PDF binaries are gitignored. Convert with `pdftotext` or similar before indexing.

Do not commit copyrighted full commercial PDFs to the repo.
